# 要件定義書 - タスク管理アプリ(Trello風)

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | タスク管理アプリ(Trello風) |
| 目的 | スクール課題として、Trelloのようなカンバン形式のタスク管理アプリを開発する |
| 開発形態 | 個人開発 |
| 想定ユーザー | このアプリを使って自分のタスクを管理する個人ユーザー(1人での利用を想定。ログイン機能なし) |

## 2. 背景・目的

タスクをカテゴリ(進捗状況)ごとに分類し、ドラッグ&ドロップで直感的に管理できるアプリを作る。
本課題を通じて、要件定義から設計・実装までの一連のアプリ開発の流れを学ぶことを目的とする。

## 3. 機能要件

| No | 機能名 | 内容 |
|---|---|---|
| F1 | タスクの一覧表示 | 「未着手」「作業中」「完了」の3カテゴリに分けてタスクカードを表示する |
| F2 | タスクの追加 | 各カテゴリの「＋タスクを追加」ボタンからモーダルを開き、タイトル・説明文・優先度・期限を入力して登録する |
| F3 | タスクの編集 | タスクカードの「編集」ボタンから、登録済みの内容を変更できる |
| F4 | タスクの削除 | タスクカードの「削除」ボタンからタスクを削除できる |
| F5 | 優先度の表示 | 優先度(高・中・低)を色分けしてカードに表示する(高=赤、中=黄、低=緑) |
| F6 | 期限日の表示・強調 | 期限日をカードに表示する。期限日が本日の場合は強調表示、期限日を過ぎている場合は「期限切れ」ラベルを表示する |
| F7 | ドラッグ&ドロップでの移動 | タスクカードをドラッグして別のカテゴリ(列)に移動できる。移動するとカテゴリの状態が更新される |
| F8 | データの永続化 | 追加・編集・削除・移動した内容はブラウザを閉じたり再読み込みしても保持される(localStorage利用) |

## 4. 非機能要件

| No | 項目 | 内容 |
|---|---|---|
| N1 | 動作環境 | PCのモダンブラウザ(Chrome等)で動作すること。サーバー不要、ブラウザのみで完結する |
| N2 | 使用技術 | HTML / CSS / JavaScript(素のJS、フレームワーク不使用) |
| N3 | データ保存先 | ブラウザのlocalStorage(外部データベース・サーバーは使用しない) |
| N4 | 想定利用人数 | 1人(マルチユーザー・アカウント機能は対象外) |

## 5. 画面構成(ワイヤーフレーム)

```
┌─────────────┬─────────────┬─────────────┐
│  未着手      │  作業中      │  完了        │
│ [+タスクを追加] │ [+タスクを追加] │ [+タスクを追加] │
│             │             │             │
│ ┌─────────┐ │ ┌─────────┐ │ ┌─────────┐ │
│ │タイトル   │ │ │タイトル   │ │ │タイトル   │ │
│ │説明文     │ │ │説明文     │ │ │説明文     │ │
│ │優先度:高(赤)│ │ │優先度:中(黄)│ │ │優先度:低(緑)│ │
│ │期限:9/20 │ │ │期限:本日⚠️│ │ │期限切れ🔴│ │
│ │[編集][削除]│ │ │[編集][削除]│ │ │[編集][削除]│ │
│ └─────────┘ │ └─────────┘ │ └─────────┘ │
└─────────────┴─────────────┴─────────────┘
```

タスク追加・編集時は、画面中央にモーダルポップアップでフォームを表示する。

## 6. データ設計

タスク1件を以下の項目を持つオブジェクトとして管理する。

| 項目名 | 型 | 内容 |
|---|---|---|
| id | 文字列 | タスクを一意に識別するID |
| title | 文字列 | タスクのタイトル(必須) |
| description | 文字列 | タスクの説明文(任意) |
| priority | 文字列 | 優先度("高" / "中" / "低") |
| dueDate | 日付 | 期限日 |
| status | 文字列 | カテゴリ("未着手" / "作業中" / "完了") |
| createdAt | 日時 | 作成日時(並び順の管理などに使用) |

## 7. 対象外(スコープ外)の機能

以下は本バージョンでは対象外とする。将来的な拡張候補として記載する。

- ユーザー登録・ログイン機能
- 複数人での共有・同時編集
- サーバー・データベースを使ったデータ保存
- タスクの検索・絞り込み
- カテゴリ(列)自体の追加・削除
